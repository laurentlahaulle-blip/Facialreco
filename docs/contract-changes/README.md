# Propositions de changement de contrat

Un fichier par proposition : `<lot>-<sujet>.md`, avec :

- **Besoin** : ce qui bloque, avec un exemple.
- **Changement proposé** : diff ou signature exacte (contrats, schéma SQL, dépendance).
- **Compatibilité** : impact sur les autres lots.
- **Statut** : proposé / accepté / refusé (renseigné par le coordinateur).

Seul le coordinateur modifie `contracts/`, `pipeline/`, `pyproject.toml` et `uv.lock`.
